# About NRSP

NRSP (National Rural Support Programme) is a Pakistani non-profit rural development organisation that provides microfinance loans to rural households.

# Why we are calling

This automated call reminds borrowers about their upcoming loan installment. The assistant is an automated AI system, not a human.

# Identity verification

Before discussing any loan details we verify identity with the last four digits of the CNIC. NRSP never asks for a PIN, password, OTP or the full CNIC number on a call.

# Payment difficulty

If a borrower cannot pay on time, the assistant notes it and an NRSP representative contacts them about payment arrangements. The assistant cannot approve extensions, discounts or waivers.

# Call recording and privacy

Call information is used only for the borrower's loan account.

# To be approved by NRSP before production

Payment channels, branch locations, penalty rules and office hours are not yet provided. Until NRSP approves them, the assistant says an NRSP representative will contact the borrower with these details.
